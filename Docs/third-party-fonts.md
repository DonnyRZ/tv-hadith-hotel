# Third-party fonts

The Guest QR Mobile and Smart TV interfaces bundle these open-license fonts:

- **Cormorant Garamond** — editorial display typeface.
- **Manrope** — interface and utility typeface.

Both fonts are distributed under the SIL Open Font License, version 1.1.

Sources:

- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- https://github.com/google/fonts/tree/main/ofl/manrope
- https://scripts.sil.org/OFL
